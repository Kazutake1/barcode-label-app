# バーコードラベル作成アプリ

iPhone・iPad・MacのSafariで利用するバーコードラベル作成・印刷Webアプリです。

- JAN-13・JAN-8・UPC-Aの番号を入力してバーコード生成
- カメラからのバーコード読み取り（HTTPS・初回通信が必要）
- 商品名とバーコードを並べたラベル印刷、A4／B5対応
- 商品情報は端末のブラウザ内に保存し、サーバーには保存しません

印刷されたバーコードは、実際の業務に使用する前に読み取り確認を行ってください。

GitHub Pagesで公開する場合は、Settings → Pages → Deploy from a branch → main / (root) を選択してください。
