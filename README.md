# バーコードラベル作成アプリ

iPhone・iPad・MacのSafariで利用するバーコードラベル作成・印刷Webアプリです。

- JAN-13・JAN-8・UPC-Aの番号を入力してバーコード生成
- カメラからのバーコード読み取り（HTTPS・初回通信が必要）
- 商品名とバーコードを並べたラベル印刷、A4／B5対応
- 商品情報は端末のブラウザ内に保存し、サーバーには保存しません

## 安全な運用

- 店舗業務の前に、実寸で印刷し、レジでバーコードが正常に読み取れることを確認してください。
- 商品名・フォルダ・印刷リストはブラウザ内に保存されます。端末を紛失、初期化するとデータを失う可能性があります。定期的にバックアップを保存してください。
- バックアップ時に8文字以上のパスワードを入力するとAES-256-GCMで暗号化したJSONを保存します。復元時も同じパスワードが必要です。パスワードはアプリ内に保存しません。パスワードを忘れると暗号化バックアップは復元できません。
- 従来の暗号化されていないJSONバックアップも、引き続き読み込めます。パスワードが空欄の場合、バックアップは暗号化されません。
- カメラ読み取りにはバージョンを固定したZXingライブラリを使用します。初回はインターネット接続が必要です。CDN経由の配信を完全に排除するには、依存スクリプトを検証済みの状態でローカル配置する追加対応が必要です。

## 回帰テスト

Node.js 20以上で、追加パッケージをインストールせずに実行できます。

```sh
node --check app.js
node --check sw.js
node --test tests/regression.test.mjs
```

GitHub Actions はmainへのpushとpull requestで同じ検査を行います。JavaScriptの構文・主要バーコード規則・保存失敗・カメラ停止競合・バックアップ互換と暗号化・CSP・印刷CSSをカバーします。iOSの実機カメラ・印刷・Safariレイアウトは別途実機確認が必要です。

GitHub Pagesで公開する場合は、Settings → Pages → Deploy from a branch → main / (root) を選択してください。
